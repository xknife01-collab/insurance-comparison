=========================================
[인슈어테크 B2B SaaS (대리점/지점 대상) 비즈니스 모델 및 영업 기획서]
=========================================

1. 비즈니스 모델 (BM) 개요
- 타겟 고객: 개별 보험 설계사가 아닌 "보험 대리점(GA)의 지점장 또는 본부장"
- 과금 모델: 지점 단위 월정액 구독 모델 (예: 지점당 월 50만 원 ~ 100만 원)
- 핵심 가치: 대리점 자체 DB 생산 자동화 및 신입 설계사 리크루팅 무기 제공

2. 대리점(지점장) 대상 핵심 세일즈 포인트 (Why buy this?)
① "돈 주고 사는 가짜 DB는 끝났습니다."
   - 고객이 직접 시뮬레이션을 돌려보고 남긴 고품질(Inbound) 진성 DB를 지점 소속 설계사들에게 매일 무상으로 공급할 수 있습니다.
② "최고의 리크루팅(설계사 채용) 무기입니다."
   - 신입 설계사 면접 시, "우리 지점에 입사하면 AI 보험 앱에서 나오는 DB를 매일 쏴준다"고 제안하여 압도적인 채용 경쟁력을 가집니다.
③ "법적/심의 리스크 일괄 해결"
   - 지점 단위로 대표 심의를 1회만 통과하면, 소속 설계사 수십 명이 합법적으로 마케팅에 활용할 수 있습니다.

3. 향후 개발해야 할 3대 핵심 기술 기능 (시스템 아키텍처)
[기능 1] 화이트라벨링 (지점/설계사 전용 커스텀 링크 발급)
- 지점별 고유 접속 URL 발급 및 화면 상단(로고)/하단(설계사 정보) 동적 노출.
[기능 2] 라운드-로빈(Round-Robin) DB 자동 분배 시스템
- 고객이 남긴 DB를 소속 설계사 10명에게 순차적으로 자동 할당 및 카카오 알림톡 전송.
[기능 3] 계층형 관리자 대시보드 (Admin Page)
- 최고 관리자(구독 통제), 지점장(DB 통계 및 분배 모니터링), 설계사(내 DB 확인)

4. 개발 로드맵 제안
- 페이즈 1: 현재 진행 중인 '비교 시뮬레이션 엔진 및 UI' 완벽 구축 (가장 중요)
- 페이즈 2: 로그인 기능 및 관리자 페이지(Admin) 뼈대 구축
- 페이즈 3: 커스텀 링크(URL 라우팅) 및 동적 프로필 렌더링 추가
- 페이즈 4: DB 저장 시 할당 로직 및 카카오 알림톡 연동, PG사 정기결제 연동

=========================================
[업데이트] 5. B2B 대리점(지점장) 대상 실전 영업(Outbound) 전략
- 네이버 지도를 활용한 오프라인 우편물(DM) 발송 콜드메일 전략
① 카탈로그 표지는 '지점장의 고통(리크루팅, 가짜 DB)'을 후벼파는 카피 사용.
② 카탈로그 정중앙에 앱 체험 QR코드를 배치하여 시각적 압도감 유도 (선착순 혜택으로 조급함 부여).
③ 우편 발송 3일 뒤 전화(마법의 콜드콜)를 걸어 QR코드 스캔을 유도.

=========================================
[업데이트] 6. 메타(인스타/페북) '고객 파일 맞춤 타겟팅' (온라인 광고 비기)
① 광고비 누수 제로: 수집한 지점장들의 번호 리스트를 광고 관리자에 업로드하여 그들에게만 핀셋 노출.
② 유사 타겟 (Look-alike): AI를 활용해 리스트에 없는 전국 10만 명의 유사 지점장/설계사 타겟 추가 발굴.
③ 리타겟팅: 클릭 이력이 있는 지점장에게 끈질기게 배너를 띄워 구독 결제 유도.

=========================================
[업데이트] 7. 투트랙(Two-track) 요금제 및 아이디 어뷰징 완벽 차단 전략
① '프로필 강제 노출' 방어막: 결제자의 사진과 카톡 링크가 앱 하단에 박히므로, 아이디를 공유하면 남 좋은 일(DB 뺏기기)을 시키게 되어 자발적으로 1인 1계정을 강제함.
② 중복 로그인 방지: 동시 접속 시 튕겨내기 및 기기 제한.
③ [Tier 1] 개인 베이직 (월 3만 원): 1인 전용 링크 1개.
④ [Tier 2] 지점장 엔터프라이즈 (월 50~100만 원): 소속 설계사용 서브 계정 50개 생성 권한 및 DB 자동 배분 기능 제공.

=========================================
[신규 업데이트] 8. 100% 자동화되는 화이트라벨링(로고/프로필 교체) 로직
플랫폼 소유자(대표님)가 수작업으로 지점 로고를 포토샵해주거나 수정해줄 필요가 전혀 없는 'Self-Service' 구축 방식.

① 관리자 페이지 내 자체 업로드 기능
- 지점장이 구독 결제 후 대시보드에 로그인하면, 본인들이 직접 자기네 대리점 로고 이미지(PNG/JPG)와 지점명(예: 잉카금융 라이즈지점)을 업로드하고 텍스트로 입력할 수 있는 설정 폼 제공.
- 소속 설계사들 역시 각자 로그인하여 본인 명함 사진과 개인 폰번호를 알아서 업로드.

② 프론트엔드 동적 렌더링 (Dynamic Rendering)
- 앱 코드는 "DB에 저장된 로고 이미지가 있으면 띄우고, 없으면 기본 텍스트를 띄워라"라는 함수로 작성됨.
- 대리점이 이미지를 등록하고 '저장'을 누르는 순간, 해당 대리점 전용 링크(myapp.com/rise) 접속 시 상단 로고와 하단 프로필이 1초 만에 자동으로 교체됨.

③ 기대 효과 (수작업 제로화)
- 구독 대리점이 1,000개로 늘어나도 플랫폼(앱) 운영자의 추가 업무가 '제로(0)'에 수렴. 진정한 자동화 SaaS 수익 모델 완성.

=========================================
[신규 업데이트] 9. 선불 충전형(Prepaid) API 크레딧 과금 시스템
건당 API 통신비(예: 하이픈 보험조회 300원, 자동차 정보 연동 등) 실비를 안전하게 회수하고 미수금 리스크를 원천 차단하는 핵심 자금 모델.

① 선불 충전형 크레딧 지갑 (Prepaid Wallet)
- 지점장 또는 개별 설계사 계정마다 독립적인 '크레딧 지갑'을 연동.
- 카카오페이, 토스페이, 신용카드 등의 PG 결제를 통해 포인트를 미리 선충전(예: 3만 원 결제 = 100회 호출 권한).

② 실시간 차감 및 소진 시 조치
- 고객이 분석 링크를 실행하여 하이픈 API 호출 성공 시 즉시 300 크레딧 자동 차감.
- 잔액이 10% 미만으로 떨어질 경우 자동 알림톡 발송: "조회 가능 잔여 횟수가 10회 미만입니다. 충전해 주세요."
- 크레딧 0원 도달 시 API 통신을 잠그고 고객 화면을 수동 입력 폼으로 우회시켜 대표님의 API 통신 비용 적자 방지.

③ 비즈니스적 기대 효과
- 미수금 리스크 제로: 후불제 결제 실패, 먹튀 및 설계사 갑작스러운 퇴사로 인한 미수 비용 원천 차단.
- 선수금 확보 및 낙전 수입: 미리 결제받은 포인트의 묶임 현금과 미사용 소멸 포인트(낙전)가 플랫폼의 추가 순수익이 됨.
- B2B 지점 영업 시 활용: 지점장이 100만 원 단위로 대량 충전한 뒤, 소속 설계사들에게 원하는 액수만큼 크레딧을 나누어(배분) 주는 관리 권한을 제공하여 지점 단체 가입 유도에 강점이 됨.
